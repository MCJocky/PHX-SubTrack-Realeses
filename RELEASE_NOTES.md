# PHX SubTrack 0.9.7 Beta

PHX SubTrack 0.9.7 brings adaptive phone and tablet support to the same APK while preserving existing subscriptions, budgets, settings, backups, and reminders.

## Highlights

- Adaptive layouts for phones, portrait tablets, landscape tablets, and resizable app windows.
- Phones remain in portrait orientation where supported; tablets can rotate freely.
- Four direct destinations: **Overview**, **Subscriptions**, **Budget**, and **Settings**.
- A cleaner overview with the distribution donut, category totals, and compact next-due information.
- Optional monthly-cost and available-budget cards that can be shown, hidden, and reordered.
- Improved tablet use of space with side navigation in landscape and bottom navigation in portrait.
- Better handling of long subscription names and large Android font sizes.
- Search now matches the beginning of a subscription name or any word in it.
- Refined PHX Frost light appearance, navigation alignment, header, and wordmark gradient.
- Clear feedback for update checks plus the last successful check time in Settings.
- GitHub release-feed fallback if the anonymous API limit is unavailable.

## Compatibility

- Existing 0.9.5 and 0.9.6 app data and backup files remain compatible.
- The APK uses the same signing certificate as 0.9.6 and can be installed as an update.
- Android 8.0 or newer is required.
- SubTrack remains free, contains no advertisements, and requires no account.

## Installation

Download **`SubTrack.apk`** below and install it over your existing SubTrack version. Android should retain all local app data. Creating a backup from **Settings → Create backup** before updating is recommended during the beta.
